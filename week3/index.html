Core Concept 1 • Logic Levels

The 2-State Binary Reality

Digital inputs answer one simple question: Is it ON or OFF?

💡 Analogue vs Digital: The Light Switch Analogy

Unlike an analogue input which measures continuous degrees (e.g. a dimmer knob producing 21.3°C, 21.4°C, 21.5°C), a digital input can only exist in two distinct states.

LOGIC 1 (HIGH)
Supply Voltage (~5.0V / 3.3V)
ON / TRUE / PRESSED / CLOSED
LOGIC 0 (LOW)
Ground (~0.0V GND)
OFF / FALSE / OPEN / IDLE
⚡ ATmega328P Logic Thresholds (5V Vcc)
Input Voltage (V_in) Interpreted Logic State Safe Operating Status
3.0V to 5.0V HIGH (1) Guaranteed HIGH (> 0.6 × Vcc)
1.5V to 3.0V Undefined / Floating ⚠️ Forbidden Zone (Metastable)
0.0V to 1.5V LOW (0) Guaranteed LOW (< 0.3 × Vcc)
💡 Key Engineering Rule: If the question can be answered with YES/NO, OPEN/CLOSED, or 1/0, it belongs on a Digital GPIO Pin!

💻 Firmware Implementation (Active-LOW Pullup)
// --- Pin Definitions: constant integers prevent accidental modification
const int BUTTON_PIN = 2; // Digital Input: Pushbutton connected to GND
const int LED_PIN = 13; // Digital Output: Built-in LED on Arduino

void setup() {
  // Enable internal ~20kΩ pull-up resistor (holds pin at 5V HIGH when open)
  // Eliminates floating pin noise without needing external resistors on breadboard
  pinMode(BUTTON_PIN, INPUT_PULLUP);

  // Configure pin 13 as digital output to source up to 20mA current
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Sample voltage: returns 1 (HIGH = ~5V) or 0 (LOW = ~0V)
  int buttonState = digitalRead(BUTTON_PIN);

  // Active-LOW Logic: pressing button connects pin to GND (0V / LOW)
  if (buttonState == LOW) {
    digitalWrite(LED_PIN, HIGH); // Apply 5V: Turn ON LED
  } else {
    digitalWrite(LED_PIN, LOW); // Apply 0V: Turn OFF LED
  }
}
🔍 Engineering Insight: With INPUT_PULLUP, pressing the switch pulls the pin down to 0V (LOW). This is standard industrial practice because it minimizes external parts!
Electrical Circuit Theory • Critical Concept

Why Floating Pins Break Systems

A digital pin left unconnected acts like an antenna picking up electromagnetic noise!

❌ 1. Floating Pin (Hazardous)

When a switch is open with no resistor connected, the input impedance is ~100 MΩ.

⚡ Voltage randomly fluctuates between 0V and 5V due to static charge, mains hum, and nearby motors.
✅ 2. External Pull-Down (10kΩ)

A 10kΩ resistor ties the pin firmly to GND (0V) when switch is open.

• Idle = 0V (LOW)
• Pressed = 5V (HIGH)
• Active-HIGH configuration
🌟 3. Internal Pull-Up (Recommended)

ATmega328P has built-in 20kΩ–50kΩ pull-up resistors enabled via firmware.

• Zero external resistors needed!
• Idle = 5V (HIGH)
• Pressed = 0V (LOW)
• Active-LOW configuration
⚠️ BTEC Exam Golden Rule: Never leave an active digital input pin floating. Always declare pinMode(pin, INPUT_PULLUP) or install a physical pull-up/pull-down resistor.
Industrial Practice • Factory Floor

Typical Industrial Digital Input Devices

How physical factory events are transformed into 1s and 0s for PLCs and Microcontrollers

🏭 Industrial Digital Sensors
  • 🛑 Emergency Stop Buttons: Twist-release mushroom buttons with Normally Closed (NC) contacts for safety.
  • 🚪 Guard Door Interlocks: Magnetic reed switches and keyed switches verifying physical safety enclosures.
  • 📏 Inductive Proximity Sensors: Detect presence of metal parts on conveyor belts without contact.
  • ✨ Optical Photoelectric Beams: Detect cartons, bottles, and pallets passing an infrared beam.
  • ⚙️ Mechanical Limit Switches: Roller-lever switches detecting end-of-travel in CNC machines and 3D printers.
🛡️ The "Fail-Safe" Industrial Standard

In industrial safety systems (BS EN ISO 13849):

Why do E-Stops use Normally Closed (NC) circuits?
During normal operation, current flows through the closed loop (HIGH / 1). If a cable is severed or damaged, the circuit drops to 0V (LOW) and the controller triggers an immediate emergency shutdown!
🏭 Industrial Law: If an emergency wire breaks, the system must fail to safe (HALT), never keep running blind!

Interactive Bottling Plant Safety Interlock

State: Bottle Missing (0)
🚪 Guard Door Interlock (Pin 3)
State: Guard Closed (1)

⚙️ Controller Decision Engine
// 1. Digital Sensor Acquisition (Boolean state mapping)
bool bottlePresent = digitalRead(PIN_BOTTLE); // Optical: HIGH (1) when object breaks beam
bool guardClosed = digitalRead(PIN_GUARD); // Reed Switch: HIGH (1) when enclosure shut
bool eStopActive = digitalRead(PIN_ESTOP); // NC Safety Switch: HIGH (1) if button tripped

// 2. Multi-Condition Safety Interlock:
// All permissive conditions must be TRUE simultaneously (&&) and E-Stop NOT active (!eStopActive)
if (bottlePresent && guardClosed && !eStopActive) {
  digitalWrite(PIN_PUMP, HIGH); // Safe to actuate: Fill Bottle (5V)
  digitalWrite(PIN_CONVEYOR, HIGH); // Advance production line (5V)
} else {
  // Fail-Safe Default: Any safety hazard immediately de-energizes actuators
  digitalWrite(PIN_PUMP, LOW); // EMERGENCY SHUTOFF (0V)
  digitalWrite(PIN_CONVEYOR, LOW); // STOP CONVEYOR (0V)
}

Real-World Engineering • Everyday Technology

Where Else Are Digital Inputs Hiding?

Modern vehicles, consumer gadgets, and robotics depend on hundreds of digital inputs

🚗
Automotive Systems

Modern vehicles contain hundreds of discrete digital inputs monitoring driver safety and powertrain status:

  • Brake Pedal Switch: Disengages cruise control & illuminates brake lights immediately.
  • Seatbelt Buckle Sensor: Warns passengers and arms active airbag pre-tensioners.
  • Door Ajar Interlock: Triggers interior courtesy illumination and cockpit alarms.
  • Reverse Gear Selector: Activates rear camera and ultrasonic parking beepers.
📱
Smartphones & Consumer Gadgets

Portable electronics rely on micro-tactile and solid-state digital inputs for instant user interaction:

  • Power & Volume Buttons: Hardware interrupt triggers for display and volume control.
  • Headset Jack Detect: Mechanical switch detects insertion to route audio stream.
  • Fingerprint Touch Sensor: Capacitive touch line wakes processor from deep sleep.
  • Optical Proximity Sensor: Shuts down touch screen when phone is held to your ear.
🏠
Security & Smart Building IoT

Intruder alarm panels and home automation hubs continuously poll digital security loops:

  • Magnetic Door & Window Contacts: Reed switches detect perimeter breaches.
  • PIR Motion Detectors: Solid-state relay pulse indicates infrared motion presence.
  • Smart Lock Deadbolt Sensors: Verifies if the physical mechanical lock is engaged.
  • Enclosure Tamper Switches: Normally Closed circuit alerts if case is pried open.
🤖
Robotics & Mechatronics

Autonomous robots and CNC machinery use digital boundaries for spatial navigation and protection:

  • Physical Collision Bumpers: Microswitches trigger emergency obstacle avoidance.
  • Optical Line Following: High-contrast photo-interrupters track black arena lines.
  • Axis End-Stop Limit Switches: Calibrates mechanical zero-homing for 3D printers.
  • Safety Light Curtains: Multi-beam optical barriers halt robotic arms if breached.
💡 The Universal Test: If the sensor only outputs Presence / Absence or Closed / Open, it is wired to a digital input!

Practical Lab Brief • Next 40 Minutes

Lab Challenge: The Dual-Button Machine Guard

Design your system architecture, draw circuit schematics, and implement the physical hardware

🛠️ Circuit Hardware Requirements
  • Arduino Uno Rev3 + USB Cable
  • Pushbutton 1 (START): Connected to Pin 2 with INPUT_PULLUP.
  • Pushbutton 2 (E-STOP): Connected to Pin 3 with INPUT_PULLUP.
  • Green LED (RUN): Pin 12 in series with a 220Ω resistor.
  • Red LED (STOP/FAULT): Pin 13 in series with a 220Ω resistor.
  • Amber / Yellow LED (ALERT): Pin 8 in series with a 220Ω resistor.
📐 Engineering Design & Logic Stages
  1. Block Diagram Design: First, sketch an Input → Process → Output (IPO) system block diagram showing all signal paths and pin mappings.
  2. Circuit Schematic: Draw the full electrical schematic diagram including pull-up switches and LED current-limiting resistors before wiring.
  3. Operational Logic:
    • When START is pressed: Green LED turns ON; Red & Amber LEDs turn OFF.
    • When E-STOP is pressed: Green LED turns OFF immediately; Red turns ON, and Amber LED blinks as an active hazard alert!
  4. Verification: Probe pin voltages with the DMM and capture Serial Monitor telemetry.
💡 Professional Workflow: Block Diagram → Circuit Schematic - software design → Breadboard Assembly → Firmware Code → Verification.
