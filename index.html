Unit 6: Microcontroller Systems for Engineers

A mandatory, externally assessed practical unit worth 120 guided learning hours. Master embedded circuit design, C/C++ firmware engineering, hardware debugging, and structured documentation on modern microcontrollers.

⏱️ Assessment Format & Dates
12-Hour Supervised Set Task
Spread over up to four consecutive working days in an engineering workshop/lab (4th – 7th May 2027), rather than a traditional written exam.
🎯 Total Marks & Grade Thresholds
80 Marks Total
Criteria-based grading thresholds:
Pass: 28–39 Merit: 40–53 Distinction: 54–80
📦 Core Deliverables
Electronic Booklet & Video
Electronic task booklet in PDF format, a video demonstration (max 3 minutes), and a signed authentication sheet.
⚙️ The Six Key Exam Activities (Physical Prototype Lifecycle)
Activity 1 • Management
Planning & System Design
Creating a structured project time log and Gantt chart schedule using spreadsheet software.
Activity 2 • Analysis
Analysis of Client Brief
Assessing technical requirements, operational constraints, sensor inputs, and actuator outputs.
Activity 3 • Specification
System Design
Drafting structured pseudocode, algorithm logic flowcharts, and electronic circuit schematics.
Activity 4 • Practical Build
System Assembly & Programming
Wiring electronic components safely and uploading C/C++ code to hardware (Arduino / Raspberry Pi Pico).
Activity 5 • Verification
System Testing & Result Analysis
Rigorous functional testing, safety interlocks, and handling unexpected events (power cuts / emergency stops).
Activity 6 • Evidence
Video Demonstration
Recording a concise, high-clarity video (max 3 min) capturing the physical prototype operating in real time.
