Section 4: The PC to MCU Development Chain (B1)

5. Trace the toolchain stages from code creation to standalone execution:
Stage 1: Source Code Creation (PC) → Engineer writes C/C++ sketch in Arduino IDE.
Stage 2: Compilation & Assembly (PC) → avr-gcc compiles high-level code into machine instructions (.hex binary).
Stage 3: USB Transmission (PC → Uno) → avrdude transmits binary over USB via ATmega16U2 USB-to-serial converter.
Stage 4: Bootloader Flashing (Uno) → 0.5 KB Optiboot bootloader receives bytes and writes them directly into ATmega328P Flash memory.
Stage 5: Autonomous Execution (Uno) → Microcontroller resets and executes setup() once, then loops loop() indefinitely.
