Engineering Practice • Real-World Sensors

Types of Analog Inputs in Modern Systems

How microcontrollers measure continuous physical forces, temperatures, and motion across industry

🎛️
Position, Angle & Motion

Mechanical sensors that measure rotation angle, sliding distance, or user control dials.

• Devices: Rotary potentiometers, linear slider pots, joysticks, throttle pedals.
• Where used: EV accelerator pedals, robotic arm joint feedback, audio mixing desks.
• How it outputs: A sliding wiper outputs a smooth voltage proportional to position.
🌡️
Temperature & Thermal Sensors

Thermal transducers that measure temperature changes with high accuracy.

• Devices: NTC/PTC Thermistors, TMP36 ICs, analog RTD sensors.
• Where used: EV battery cooling systems, 3D printer hotends, HVAC thermostats.
• How it outputs: Electrical resistance changes smoothly with heat, varying the voltage (10mV/°C).
☀️
Light & Optical Sensors

Photosensitive components that detect ambient brightness, reflections, and illumination.

• Devices: Light Dependent Resistors (LDRs / Photoresistors), phototransistors.
• Where used: Automatic vehicle headlights, solar panel trackers, phone auto-brightness.
• How it outputs: Absorbed photons free electrons; resistance drops from 1MΩ (dark) to 400Ω (bright).
🗜️
Force, Pressure & Liquids

Mechanical and environmental sensors that detect physical force, weight, pressure, or moisture.

• Devices: Force-Sensing Resistors (FSRs), strain gauges, pressure transducers, soil probes.
• Where used: Digital scales, robotic surgical grippers, hydraulic brake pressure, smart irrigation.
• How it outputs: Mechanical squeezing or fluid conductivity varies the circuit's analog voltage.
💡
The Universal Rule of Analog Inputs: Even though temperature, light, pressure, and dials seem totally different, every single one transforms physical changes into one universal signal: a smooth voltage between 0V and 5V. Arduino reads all of them using the exact same function: analogRead(A0);!
Our Sensor Today • The Rotary Knob

What is a Potentiometer?

Why we start with a potentiometer: it's a simple, hands-on 3-pin volume knob!

🎛️ How It Works

Inside the knob is a circular strip of carbon. As you turn the knob, a small metal pointer (called the wiper) slides across the strip:

Pin 1: Connects to 5 Volts (Power).
Middle Pin (Wiper): Connects to Pin A0 on the Arduino. It outputs whatever voltage you pick!
Pin 3: Connects to GND (Ground / 0V).
⚡ What the Middle Pin Sends to Arduino

Turning the knob smoothly divides the 5 Volts:

Turn fully left (counter-clockwise): 0.0 Volts
Turn to the middle: 2.5 Volts
Turn fully right (clockwise): 5.0 Volts
💡 Key takeaway: The knob lets you dial in any voltage you want between 0 and 5 Volts.
Inside the Arduino • The Voltage Translator

How Arduino Reads Voltage: The ADC

Computers only understand numbers. The ADC turns volts into numbers you can use!

🤔 What is an ADC?

ADC stands for Analogue-to-Digital Converter.

The Arduino CPU cannot do math on "volts". It needs a normal integer number. The ADC measures the voltage on Pin A0 and converts it into a number between 0 and 1023:

0 Volts ➔ 0
2.5 Volts ➔ 512
5.0 Volts ➔ 1023
❓ Why 0 to 1023?

The Arduino Uno uses a 10-bit converter. In binary, 10 bits can store 210 = 1,024 different values (from 0 to 1023).

• That means the 5 Volts is chopped into 1024 tiny steps.
• Each step is about 0.005 Volts (5 millivolts).
• This makes it very sensitive and smooth!
✨ In your code, you get this number with one line:
int sensorValue = analogRead(A0);
The Build Plan • How It Fits Together

The Project: Variable-Speed Strobe Light

How does reading a number make a light change speed? Here is the logic:

Step 1: Read Number

Arduino reads the knob value and saves it into sensorValue (between 0 and 1023).

Step 2: Turn LED ON & Wait

Turn the LED ON, then wait for delay(sensorValue) milliseconds.

Step 3: Turn LED OFF & Wait

Turn the LED OFF, then wait for another delay(sensorValue) milliseconds.

💡 Why does the speed change?
• If the knob is turned down to 50, the Arduino only waits 50 milliseconds. The light flashes super fast! (Strobe effect)
• If the knob is turned up to 1000, the Arduino waits 1 whole second on and 1 whole second off. The light blinks very slowly.

The Program • Clean & Simple

The Arduino Code (Line by Line)

This short program is all you need to make the entire project work:

💻 Full Working Sketch
int potPin = A0;  // Knob is on Pin A0
int ledPin = 13;  // LED is on Pin 13

void setup() {
  pinMode(potPin, INPUT);    // Configure A0 as analog input
  pinMode(ledPin, OUTPUT);   // LED pin as output
  Serial.begin(9600);  // Start Serial communication
}

void loop() {
  int sensorValue = analogRead(potPin);

  Serial.print("ADC Value: ");
  Serial.println(sensorValue);  // Send number to laptop

  digitalWrite(ledPin, HIGH);  // Light ON
  delay(sensorValue);          // Wait
  digitalWrite(ledPin, LOW);   // Light OFF
  delay(sensorValue);          // Wait
}
📖 What Each Line Does
setup(): Runs once when Arduino turns on. It configures potPin (A0) as an INPUT, ledPin as an OUTPUT, and starts the Serial link at 9600 speed.
analogRead(A0): Checks the knob right now and gets a number between 0 and 1023.
Serial.println(): Prints that number onto your computer screen so you can see it.
delay(sensorValue): Pauses the program for that number of milliseconds before switching the light.
Debugging Skills • Finding Faults

Why the Serial Monitor is Your Best Friend

It lets you see inside the Arduino's brain instead of guessing what went wrong!

🚫 Without the Serial Monitor ("Guessing Blind")

Imagine your LED is not flashing. You have no screen:

  • Is the knob wire loose?
  • Is the LED blown?
  • Is the code frozen?
  • Is the Arduino reading 0?

You have no idea! You have to guess.

✅ With the Serial Monitor ("Total Clarity")

You open the Serial Monitor and look at the numbers:

  • If you turn the knob and the numbers change (e.g. 100 ➔ 600), the knob is 100% working!
  • If the numbers are stuck at 1023, you know a ground wire came loose.
  • If nothing prints, you forgot Serial.begin(9600).

You can fix the problem in 5 seconds!

💡 Pro Tip for the Lab: Make sure the bottom-right corner of your Serial Monitor window says 9600 baud. If it says something else, you will see weird question marks instead of numbers!
